# Une Note de frais est immuable après génération du PDF

Une fois le PDF final généré pour une Note de frais, elle devient totalement immuable — personne, pas même l'administrateur, ne peut plus la modifier. Le PDF marque la validation effective des données financières, au même titre qu'une facture émise. Ce choix traite la génération du PDF comme un point de non-retour comptable, plutôt que de permettre des corrections a posteriori qui fragiliseraient l'archive officielle.

La façon de corriger une erreur découverte après coup (nouvelle note, correction manuelle hors application, autre mécanisme) reste un point ouvert, non tranché par cet ADR.
